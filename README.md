# India Road Accident Analysis Dashboard (2014-2017) 🚦🚗

## Project Overview
This interactive Power BI dashboard provides a comprehensive analysis of road accidents across various States and Union Territories in India over a four-year period. The goal of this project is to identify high-risk zones, peak accident hours, and year-over-year trends to help visualize road safety data effectively.

## Key Insights & Features
* **Annual Trends:** Visualized the growth/decline of accidents from 2014 to 2017.
* **Peak Hour Analysis:** Identified that the **15:00 - 21:00 (3 PM - 9 PM)** window is the most high-risk period for road travel.
* **Regional Benchmarking:** Categorized the **Top 10 High-Risk** and **Top 10 Safest** states.
* **Day vs. Night Comparison:** Created a custom DAX column to segment accidents based on light conditions.
* **Interactive Heatmap:** A state-wise hourly risk matrix that highlights specific danger zones using conditional formatting.
* **Dynamic Filtering:** Included a **State/UT Slicer** that allows users to filter the entire dashboard for localized insights.

## Technical Stack
* **Tool:** Power BI Desktop
* **Data Source:** Road accident statistics (India)
* **Data Transformation:** Power Query (Data cleaning, column renaming, and type conversion)
* **DAX (Data Analysis Expressions):** Created custom calculated columns for "Day or Night" segmentation.
* **Visuals:** Area Charts, Clustered Bar/Column Charts, Donut Charts, Matrix (Heatmap), and KPI Cards.

## How to View
1. Download the `.pbix` file from this repository.
2. Open the file using **Power BI Desktop**.
3. Use the **State/UT Slicer** on the bottom right to interact with the data.
